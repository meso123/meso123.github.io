04 Cell & Line Detection Solo · Computer vision +

From fluorescence cells to architectural lines.

Implemented Sobel, Prewitt and Laplacian kernels, tested Canny threshold sensitivity against HEp-2 cell ground truth, and tuned a probabilistic Hough transform from 1,075 noisy lines to 13 structural detections.

The analysis found Sobel and Prewitt more complete on low-fluorescence cells, while Canny produced the thinnest edges but missed weaker boundaries.

A concurrent TCP rule engine.

A pthread-based C client/server with add, delete, list, check and command-history operations. Mutexes protect shared policy and log state while each accepted socket is handled on a detached worker thread.

Compiled and exercised successfully with GCC. Current limits include fixed-size replies and incomplete range matching, so it is presented as systems coursework—not production security software.
