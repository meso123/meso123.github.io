03 / TEAM PROJECT / FULL STACK

Study Hard

A collaborative study-management platform connecting courses, assignments, goals, groups, notes and motivational progress.

TEAM7 students
MY SLICEAchievements, leaderboard and shared accessibility controls
DELIVERYFull-stack workflow with database-backed CRUD and CI/CD

Owning one vertical slice end to end.

Large team projects can make individual ownership hard to see. My responsibility was explicit: take the Achievements experience from data operations through interface behaviour, then implement accessibility features used beyond that page.

The achievement loop

The feature supported points, streaks, achievement states, filtering and leaderboard ranking. That meant coordinating interface states with persistent data and fitting the work into a broader domain model maintained by the team.

Accessibility as shared infrastructure

I also delivered high-contrast and low-saturation presentation controls and shared theme behaviour, treating accessibility as a system concern rather than one isolated screen.

My best contribution was not just a page. It was a complete, testable slice that the rest of the application could rely on.
EVIDENCELeaderboard described as “impressively implemented”
TECHJHipster, Java, relational data, web UI

What team delivery taught me.

  • Agreeing interfaces early matters as much as writing the implementation.
  • A vertical slice makes ownership and integration risk visible.
  • Accessibility controls should be consistent across every route.
  • Useful documentation reduces the cost of other people touching your code.
