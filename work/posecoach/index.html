PoseCoach

Real-time AI exercise coaching, entirely on a phone—with private camera analysis, spoken corrections and evidence-led evaluation.

ROLESolo developer & researcher
STACKReact Native, MoveNet, TensorFlow.js, Node.js, Firebase
RESULT99.1% rep-count accuracy across 792 evaluated repetitions
Read technical report ↗

From a camera feed to useful coaching.

PoseCoach uses MoveNet Lightning to turn each frame into 17 body keypoints. A rule-based state machine recognises squats, push-ups and lunges, counts completed repetitions and checks exercise-specific biomechanics. Spoken feedback lets the user respond without looking away from the movement.

The constraint

A fitness coach cannot feel helpful if every correction arrives late—or safe if raw camera data leaves the phone. The core analysis therefore stays on-device. Network access is reserved for optional, session-grounded post-workout reports.

The engineering decision

The deterministic pipeline remains authoritative. Five small neural networks run alongside it as an experimental layer, which exposed a real synthetic-to-real domain gap without making the live workout depend on unreliable predictions.

The useful AI is not the flashiest model. It is the system that stays responsive, private and honest about uncertainty.
DATA58,100 purpose-built synthetic samples
MODEL OVERHEAD127 KB across five networks
ROBUSTNESS30° jitter gate removed stationary false counts in testing

What I learned.

  • Real-world pose estimation needs filtering, gating and exercise context—not just raw keypoints.
  • Synthetic data can validate architecture but does not replace representative human motion.
  • Evaluation must separate rep counting, form detection, latency and user experience.
  • Clear rule-based fallbacks can make an experimental ML layer safe to explore.
