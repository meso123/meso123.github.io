Interval

A timetable-aware fitness prototype built from interviews, coded in React and changed by usability evidence.

MY ROLEPrototype lead, discovery rewrite and final case-study compilation
STACKReact 18, Vite, Tailwind CSS
RESEARCH4 interviews + 4 usability tests
Open live prototype ↗

Fitness had to fit the timetable—not fight it.

Students did not need another generic workout library. Interviews pointed to a planning problem: finding realistic windows around lectures, commutes and exam pressure. Interval turns those constraints into an actionable weekly plan.

From research to flow

The coded prototype covers onboarding, timetable setup, exam mode, workout discovery, active sessions and progress. I led implementation of the 13-screen experience, rewrote the discovery narrative and produced detailed design annotations.

Evidence changed the design

Testing found friction in timetable entry and a risky accidental-exit path during workouts. The final concept introduced Canvas timetable import and a clear exit confirmation rather than defending the original flow.

The strongest feature was not on the first wireframe. It appeared because the usability test made the friction impossible to ignore.
